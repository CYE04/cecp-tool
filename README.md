# CECP 专注倒计时

纯前端单文件高颜值专注倒计时工具（含 CECP Logo、可爱陪伴小猫咪、5 套毛玻璃主题、中英文切换、切后台精准计时与内置白噪音）。

## 在 Halo 中嵌入

将本目录推送到 GitHub 并开启 GitHub Pages 后，在 Halo 自定义页面或文章中插入 HTML 代码块：

```html
<iframe
  src="https://cye04.github.io/cecp-tool/"
  style="width: 100%; min-height: 700px; border: none; border-radius: 16px;"
  allow="fullscreen"
  loading="lazy">
</iframe>
```
