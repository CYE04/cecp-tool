# 静谧专注空间 (Focus Space)

纯前端单文件高颜值专注工具，适合嵌入 Halo 博客或作为桌面沉浸时钟使用：

- **🍅 专注倒计时**：番茄专注 (25m) / 短休 / 长休 / 自定义分钟，支持本次专注任务记录与今日完成次数统计。
- **🌬️ 4-7-8 呼吸引导**：发光呼吸球动画引导吸气、屏息、呼气，快速放松减压。
- **⏳ 时间进度条**：实时可视化展示今年、本月、本周、今日已过百分比。
- **🎧 内置白噪音**：纯 Web Audio API 合成细雨、海浪、暖噪，无需外部音频文件。
- **🎨 5 套氛围主题 + 全屏模式**：极简纸白、深海静谧、日落余晖、森林呼吸、暗夜极客，支持一键全屏沉浸。

## 在 Halo 中嵌入

将本目录推送到 GitHub 并开启 GitHub Pages 后，在 Halo 自定义页面或文章中插入 HTML 代码块：

```html
<iframe
  src="https://cye04.github.io/cecp-tool/"
  style="width: 100%; min-height: 660px; border: none; border-radius: 16px;"
  allow="fullscreen"
  loading="lazy">
</iframe>
```
